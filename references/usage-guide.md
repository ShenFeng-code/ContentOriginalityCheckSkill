# 文案查重使用指南

## 三种查重模式

### 1. 单篇自查 (self_check)
检测单篇文案内部段落重复。
- 输入：一段文本
- 适用场景：检查文章内部是否有重复段落、凑字数、循环论证

### 2. 多篇互查 (cross_check)
多篇文档两两比对。
- 输入：2 篇及以上文档
- 适用场景：投稿审核、多版本文案对比、团队协作去重

### 3. 文档库比对 (db_check)
将目标文案与本地文档库逐一比对。
- 输入：目标文本 + 文档库目录
- 适用场景：检测新文案是否与历史文章重复、内容复用度评估

## 输入方式

| 方式 | 说明 |
|------|------|
| 粘贴文本 | 直接提供文本内容 |
| 文件路径 | TXT / PDF / DOCX / Markdown |
| 文件夹 | 批量读取目录下所有支持文件 |
| URL | 联网抓取网页文本 |

## 输出报告

Markdown 格式，包含：
- 查重概况（篇数/段落数/重复率）
- 相似段落对照表
- 相似度排名
- 联网查重结果（如开启）

## 阈值说明

默认相似度阈值为 0.5（50%）。用户可调整，常见建议：
- 0.3：宽松——标记所有模糊相似
- 0.5：标准——标记明显相似
- 0.7：严格——仅标记高度相似
- 0.8：极严——仅标记几乎相同
